# Mukesh Thakkar — Static Website

A responsive, single-page static website built with HTML, CSS and vanilla JavaScript. It does not require a database, backend, or environment variables.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current copyright year
- `mukesh-thakkar.jpg` — supplied profile photo

## Preview locally
Open `index.html` in a browser. For a local server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Deploy on GitHub Pages
1. Create a GitHub repository and upload all four files to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then Save.
5. Wait for GitHub Pages to publish the site.

You can also deploy this folder to Vercel as a static site. No database configuration is required.
